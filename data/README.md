# data

This folder holds the image lists and the SHA-256 manifests of the external datasets. The images themselves are not
redistributed; [`docs/data.md`](../docs/data.md) explains where to obtain them, where to place them and how to check them.

| Path | Content |
|---|---|
| `external/_pilot/` | pilot BOSSbase images and screening BOWS2 images |
| `external/bossbase/MANIFEST.sha256` | SHA-256 of the 10 000 BOSSbase 1.01 PGM files |
| `external/bows2/MANIFEST.sha256` | SHA-256 of the 10 000 BOWS2-Original PGM files |
| `external/alaska2/` | E7 and E1-bis image lists (index, camera model) and SHA-256 of the ALASKA2 TIFF files |
| `external/raw/SHA256SUMS` | SHA-256 of the downloaded archives |
