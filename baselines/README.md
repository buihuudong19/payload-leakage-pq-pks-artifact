# baselines

`bl1_reference/` (not tracked) is where the BL1 reference implementation is expected. It is not redistributed with this
repository; see [`docs/baselines.md`](../docs/baselines.md) for the list of modules and for the environment variable
`PQPKS_BL1_REFERENCE_DIR`.

`bl1_reference.SHA256SUMS` lists the SHA-256 of the nine reference modules used in the pilot rounds; check a local copy with
`python scripts/setup/check_bl1_reference.py`.
